# Workshop Agentic Engineering bei Lekkerland

Unterlagen von atra für Lekkerland: Erstworkshop vom 23. bis 25. November 2026 in Frechen, die Agent Factory und die Folgetermine.

## Aufbau

| Ordner | Inhalt | Ändert sich |
|---|---|---|
| `01-erstworkshop/` | Vorbereitung, die drei Workshoptage, Übungen, Ergebnisse | Nach dem Workshop nicht mehr |
| `02-agent-factory/` | Die Factory: Überblick, Einrichtung, Bedienung, Betrieb, Sicherheit | Laufend |
| `03-folgetermine/` | Ein Ordner je Termin, benannt nach Datum (`JJJJ-MM-TT-thema`); Vorlage in `vorlage/` | Ein Ordner je Termin |
| `04-laufend/` | Offene Punkte, Entscheidungen, Glossar | Laufend |

Leser der Factory-Unterlagen:

- `02-agent-factory/einrichtung/`: Admins, einmalig.
- `02-agent-factory/bedienung/`: die Teams, täglich.
- `02-agent-factory/betrieb/`: wer die Factory verantwortet.
